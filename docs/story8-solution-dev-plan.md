## 1. 어떤 솔루션인가

**한 줄 정의**: 인간 작가가 설계한 캐릭터·세계관을 AI가 숏드라마로 빠르게 시제품화하고, 시청자 반응으로 검증된 것만 본편으로 만들어 플랫폼에 공급하는 **AI 숏드라마 IP 제작 시스템**. 모든 결과물에는 "누가 무엇을 만들었는지"를 증명하는 권리 기록이 붙는다.

**핵심 원리**: AI는 작가를 대신해 이야기를 쓰는 주체가 아니다. 작가가 결정한 것을 실행·검증·시각화하는 제작 엔진이다. 이렇게 해야 결과물의 저작권이 인정되고, 작가·독자·플랫폼이 거부하지 않는다.

### 1-1. 구성 모듈 (원안 3요소의 재정의)

| 모듈 | 원안 | 개발할 솔루션 | 하는 일 |
|---|---|---|---|
| **OCT UNIVERSE → 캐논 바이블** | AI가 100만 캐릭터 생성 | 캐릭터·세계관 그래프 DB + 권리 원장 | 작가가 캐릭터(기본정보·연령별 사건·前事)·관계·세계 규칙·금칙을 입력. 항목마다 작성자·승인자·버전·이용 범위를 기록 |
| **OCT KOSMO → AI 작가실** | AI가 스토리 단독 창작 | 멀티에이전트 집필·프리비즈 파이프라인 | 쇼러너가 비트를 정하면 AI가 대본 초안 → 연속성 검증(설정 모순 자동 탐지) → 캐릭터 시트·스토리보드·영상 생성. 작가가 수정·승인 |
| **STORY 8 → 검증·증명 계층** | 작가-AI 교대 집필 플랫폼 | 파일럿 검증 시스템 + S8 Proof | 3화 파일럿을 훅 버전별로 테스트해 완주율 상위만 본편 승격. 편집 이력을 해시·타임스탬프·C2PA로 봉인한 기여 증명서 발급 |

### 1-2. 작동 흐름

```
작가 바이블 입력 → AI 작가실(비트·대본 초안·연속성 검증) → 작가 수정·승인
→ 3화 파일럿 AI 제작(실사 촬영 없음, 본당 약 530만 원)
→ 독자단 블라인드 평가 + 동일 노출 A/B → 상위 20~30% 승격
→ 본편 60화(배우 실사 + AI 배경·VFX·더빙, 편당 약 9,000만 원)
→ 플랫폼 납품 · 해외 더빙판 · 캐릭터 콜라보
→ 캐릭터 자산 재사용(시즌2 원가 약 7,000만 원) · 실패 파일럿은 학습 데이터로
```

## 2. 시장성

### 2-1. 왜 지금인가

| 근거 | 수치(출처) |
|---|---|
| 숏드라마가 가장 빠르게 크는 영상 시장 | 글로벌 마이크로드라마 2025년 110억 달러 → 2030년 260억 달러, 국내 2026년 약 6,500억 원(카카오벤처스 추정) |
| 시청 시간이 넷플릭스를 추월 | ReelShort MAU 4,500만, 일 평균 35.7분(넷플릭스 모바일 24.8분) |
| AI로 제작비가 급락 | AI 적용 시 편당 제작원가 80~90% 절감, 기간 수개월 → 2~3주. 중국은 2026년 1~8월 43만 편 중 90% 이상 AI 활용 |
| 기존 읽기 플랫폼은 정체 | 웹툰·웹소설 플랫폼 12개사 2025년 영업손익 −303억 원 적자 전환, 반면 IP 공급사(CP) 9개사 영업이익 +82% |
| 공공자금이 'AI×IP'를 정조준 | K-컬처 밸류업 펀드 AI·IP 1,000억 원, 콘텐츠 IP 펀드 2,000억 원, KOCCA AI 콘텐츠 제작 지원 198억 원(2026) |

### 2-2. 돈을 내는 고객

| 순서 | 고객 | 구매하는 것 | 과금 |
|---|---|---|---|
| 1 | 숏드라마 플랫폼(비글루·케이숏·네이버웹툰·카카오엔터, ReelShort·DramaBox) | 반응 데이터·권리 증빙이 붙은 본편 | 편당 MG + 수익배분, 또는 공동제작 수수료 |
| 2 | 플랫폼·제작사·IP 보유자 | 웹툰·웹소설의 세로형 숏드라마 전환, 프리비즈·AI VFX 공정, 권리 실사 | 프로젝트 단가 → 연간 라이선스(월 300만~800만 원 [추정]) |
| 3 | 패션·유통·F&B 브랜드 | 팬덤이 검증된 캐릭터 콜라보 | 러닝 로열티 |
| 4 | 해외 플랫폼(일본·북미) | AI 더빙판 | 지역별 MG |

### 2-3. 경쟁 속 빈자리

- **플랫폼**은 자체 제작에서 손실을 낸다(리디 '칸타' 약 210억 원 손실). 외부의 검증된 공급이 필요하다는 것이 핵심 가설이다.
- **중국산 AI 양산물**은 싸지만 저품질 역풍을 맞고 있다(중국 플랫폼이 2026년 6월 한 달 저품질 투고 10.4만 건 반려).
- **네이버·카카오**는 자사 웹툰 IP 전환에 집중한다.
- 빈자리는 **"한국어 오리지널 캐릭터 + 인간 대본 + 반응 데이터 + 권리 증빙"을 갖춘 소량 고품질 공급자**다.
- 권리 증빙의 가치: AI 단독 생성물은 한·미·EU 모두 저작권이 없다. 인간 기여 기록이 없으면 영상화 계약의 권리보증을 통과하지 못한다. S8 Proof가 이 문제를 직접 해결한다.

### 2-4. 수익 규모 [추정]

| | Y1 | Y2 | Y3 |
|---|---|---|---|
| 매출 | 3.5~5억 원 | 15~25억 원 | 40~60억 원(기준 48억) |

Y3 기준 매출 구성: 플랫폼 납품 50%, B2B 서비스·라이선스 17%, 해외 15%, 공동제작 12.5%, 콜라보 6%.

**편당 경제성**: 납품가 2억 원 − 원가 9,000만 원 − 작가 러닝 2,000만 원 = 회사 몫 9,000만 원(GM 45%). 납품가가 1억 3,500만 원 아래면 완성본 납품 대신 공동제작으로 전환한다.

**한계**: 재무적 VC가 기대하는 10배 성장형 사업은 아니다. 전략적 투자자(플랫폼·F&F·제작사)·정책펀드에 맞는 사업이다.

## 3. 개발 계획

### 3-1. 기술 원칙

- **자체 AI 모델을 만들지 않는다.** Claude·GPT·Gemini 등 외부 API를 라우팅해서 쓴다. 장편 1편 API 비용 $5~45, 영상 1화 $3~180이라 비용은 병목이 아니다.
- **직접 만들 것(경쟁력)**: 캐논 바이블 그래프, 권리 원장, 연속성 검증기, S8 Proof, 모델 라우팅.
- **사서 쓸 것**: LLM, 이미지·영상 생성(Kling·Veo·Seedance), 번역·더빙, 안전 필터.

### 3-2. 아키텍처

| 계층 | 구성 |
|---|---|
| 데이터 | 바이블 그래프 DB(캐릭터·장소·사건·규칙·금칙 + 관계), 권리 원장, 캐릭터 레퍼런스 자산, 임베딩 인덱스 |
| 생성 | 쇼러너(인간) → 플롯/비트 → 캐릭터 에이전트 → 대사·지문 → 연속성 검증 → 편집(인간) |
| 시각화 | 캐릭터 시트 고정 → 스토리보드 → 영상 생성(모델 라우팅) |
| 평가 | 모순 0건 검증, 루브릭 심사(인간 라벨 일치도 κ ≥0.6), 'AI 티' 역검출, 독자단·A/B 데이터 |
| 학습 | 완주 데이터·작가 수용/거절 → 선호 쌍 → 보상모델(9~18개월 후) |
| 증명·규제 | 해시 체인 + 타임스탬프 + C2PA 기여 증명서, AI기본법 표시, 유해 콘텐츠 필터 |

### 3-3. 단계별 로드맵

| 단계 | 기간 | 개발 범위 | 완료 기준 |
|---|---|---|---|

## 4. 개발 전에 확인할 세 가지

1. **납품가**: 국내 숏드라마 플랫폼의 편당 구매 단가는 공개되지 않았다. 수급 PD 3인 인터뷰로 먼저 확인한다.
2. **권리 구조**: 플랫폼은 제작비를 내면 권리나 독점을 요구한다. 플랫폼 귀속·공동 소유·회사 보유 중 어떤 조건이 가능한지 확인한다.
3. **회사 실사**: 특허 10-2022-0131471의 상태, 기존 작품 권리, TIPS 자격(2019년 설립으로 업력 7년 초과 가능성).
